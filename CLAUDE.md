Project instructions for this repository live in **[AGENTS.md](AGENTS.md)** — one file,
so every agent reads the same rules. It is imported below; follow it as if it were
written here.

@AGENTS.md

Short version, if you read nothing else: parts are modelled in **real-world centimetres**
and shrunk to 1:40 by `scad/lib/common.scad`; a token is a small model of a piece of
furniture and **not a labelled brick**, so give it real form and real hollows before you
reach for an engraved line, and put doors, drawers and handles on the **front (−Y) face**
where a low angle can see them. Everything must print the right way up without supports.
